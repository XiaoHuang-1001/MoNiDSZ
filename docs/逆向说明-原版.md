## 四、这次没做的部分（及补法）

| 缺口 | 原因 | 补法 |
| --- | --- | --- |
| dex → Java 源码 | 本机没有 JDK/JADX；REA 的 Android provider 要求自备 `jadx-headless-mcp 0.7.1` JAR + JDK 21 | 装好 JDK 后设 `REA_JADX_MCP_JAR`，再让 REA 跑 `inspect_android_package` |
| `res/` 二进制 AXML 解码成可读 XML | apktool 同样需要 JDK，且 GitHub 被 hosts 屏蔽下不了 | 有 JDK 后 `apktool d`，或用 REA 的 `decode-android-resources` |
| 原生 `.so` 反编译 | 未装 Ghidra/IDA | 放好 Ghidra 后设 `GHIDRA_INSTALL_DIR`，用 REA 的 `open_binary`/`decompile` |
| 加固/壳 | `lib/` 里有广告与安全 SDK（穿山甲、快手、数美等），非游戏本体 | 一般无需处理 |

Java 层是广告/统计 SDK 的壳，**游戏逻辑全部在 `源码/modules` 的 250 个 JS 模块里**，
和现有 `dszmnq` 工程里的 `董事长模拟器_逆向/源码/modules` 是同一版本（可直接对照，新版只是没有文件头注释）。

## 五、把解包目录重新打成 APK

产物：`build\dszmnq_1.0.6_signed.apk`（151.3 MB，v1+v2+v3 签名，zipalign 通过）。

⚠️ 关键点：`resources.arsc` 必须 **store（不压缩）且 4 字节对齐**。
targetSdk ≥ 30 的包在 Android 11+ 上如果 arsc 被 deflate，会直接安装失败
（小米/ HyperOS 常提示“不兼容”）。`tools\repack.py` 已按此处理，别用 System.IO.Compression 的
`NoCompression` 参数——它实测仍会写成 deflate。

本机已有 Android SDK 与 JDK，只是不在 PATH 里：

```
SDK   = C:\Program Files (x86)\Android\android-sdk
BT    = %SDK%\build-tools\36.0.0
JDK   = C:\Program Files\Android\openjdk\jdk-21.0.8      （设为 JAVA_HOME）
签名  = ..\dszmnq\android\debug.keystore  (androiddebugkey / android)
```

流程（PowerShell）：

1. **重打包**：把 `apk/` 用 deflate 压成 zip，仅 `resources.arsc` 保持 store；
   `tools\repack.ps1` 就是这个逻辑（`-Src apk -Out build\unsigned.apk`）。
2. **对齐**：`zipalign -p -f 4 build\unsigned.apk build\aligned.apk`
3. **签名**：`apksigner sign --ks ..\dszmnq\android\debug.keystore --ks-pass pass:android
   --key-pass pass:android --ks-key-alias androiddebugkey --out build\dszmnq_247960_signed.apk build\aligned.apk`
4. **验证**：`apksigner verify -v build\dszmnq_247960_signed.apk`（v2/v3 均为 true）

注意：签名换成了调试证书，**不能覆盖安装原版**，装之前先卸载原版
（否则 `INSTALL_FAILED_UPDATE_INCOMPATIBLE`）。APK 内 2747 个条目与原包一一对应。

## 六、和现有迭代工程的关系

- `..\dszmnq\` 是用这套反编译产物重写出来的可玩工程（web + Cocos + APK 打包）。
- 本目录是**原版 v1.0.6 的完整工程文件**，改逻辑/查数值时以这里为准：
  - 查数值 → `源码/modules/01_config/co_*.ts`
  - 查界面行为 → `源码/modules/02_ui/W*.ts`
  - 查主循环 → `源码/modules/00_core/blController.ts`
  - 查通用控件 → `源码/modules/03_widgets/ZGGS*.ts`
- 原版**没有**独立的 config 目录：65 张配置表以常量/数组形式内联在 `源码/modules/01_config/co_*.ts` 里，
  打包后的资源（贴图、音频、预制体）在 `资源/resources/import/<uuid>` 下，需按 Cocos 的 uuid 规则解析。
