# 出包规矩（本项目级，权威版见 ../AGENTS.md）

**只允许一条命令出包，不许拆步骤手搓：**

```
tools\release.cmd              # 自增版本号
tools\release.cmd --no-bump    # 同版本重出
```

它按序做：环境自检 → 版本自增 → 游戏内版本号 → 重编 index.jsc → AXML（版本/名称/启动入口）
→ 图标印版本 → 重打包 → zipalign → 签名 → 投放桌面 → **verify_release.py 24 项终检**。

**终检不过 = 自动删除成品 + 非零退出，绝不交付半成品。**

## 三条铁律

1. **每次出包必须自增版本号**，且版本号必须同时出现在：文件名、manifest（versionName+versionCode）、
   应用名、图标红条 + 游戏内 `bhaopz`。少一处就是返工。
2. **禁止 ZIP64**（`force_zip64` 一律不许出现），否则安卓安装器直接拒绝安装。
3. **桌面只留一个 APK**：`C:\Users\20905\Desktop\最新包\dsh-fgs-<ver>.apk`。

## 已验证

`1.1.4 / versionCode 14` 用 `--no-bump` 重跑，产物 SHA-256 与首发包完全一致
（`1B4C1C21…2DCE24D`），说明构建确定性可复现；终检 24/24、EXIT=0。

## 交付话术必须是

贴 `24/24 通过` + 路径 + 大小 + SHA-256 + 三处识别点（文件名 / 图标红条数字 / 应用名），
并提醒用户：真机实际版本看 `设置 → 应用 → 董事长模拟器 → 版本`。
用户说"版本不对"时，先让他核对**文件名**，大概率装的是手机里残留的旧 APK。
